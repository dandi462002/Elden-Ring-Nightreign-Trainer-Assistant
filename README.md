## 🌌 Overview

The **Elden Ring Nightreign Companion Toolkit** is a Windows-oriented assistant application built for players who enjoy dissecting encounters, planning routes, and refining builds without friction. Rather than interfering with the core experience, this companion focuses on delivering quality-of-life conveniences: quick stat references, session logging, and a customizable overlay that stays out of your way until you summon it.

Unlike a blunt instrument, this project behaves more like a well-worn leather journal — quiet, dependable, and always ready when the road grows dark. It is crafted for Windows 11 and Windows 10 environments, with a strong emphasis on stability, low resource usage, and a clean, readable interface.

The repository you are viewing contains documentation, configuration templates, and the setup guide for the companion suite. It is maintained by enthusiasts who value transparency, respectful collaboration, and iterative improvement.

Every tarnished eventually hits a wall — a boss that refuses to fall, a build that underperforms, or a route that feels inefficient. Instead of forcing players to juggle six browser tabs and a notepad, the Nightreign Companion consolidates the essentials into a single, elegant dashboard.

## 🖼️ Screenshots and Interface Philosophy

While this README is text-forward, the companion app embraces a visual identity inspired by the twilight tone of the Lands Between — deep blues, soft golds, and readable typography. The interface avoids harsh contrast and aggressive animations, opting instead for a calm, deliberate feel.

Design principles guiding the UI:
1. **Negative space is a feature.** Crowded screens cause fatigue; we space things out.
2. **Motion with meaning.** Animations confirm actions, never distract.
3. **Predictable layouts.** Buttons live where you expect them to live.
4. **Reversible everything.** Undo is always nearby.

## 💻 System Requirements

To run the companion smoothly, the following baseline is recommended:

## ⚙️ Configuration and Profiles

Profiles are the backbone of a personalized experience. Each profile is a small bundle containing your panel layout, hotkeys, theme, and notification preferences. You can maintain separate profiles for different characters, difficulty goals, or even different moods.

Key profile concepts:
- **Default Profile** — the fallback used when nothing else is selected.
- **Session Profile** — a temporary profile that resets on exit.
- **Imported Profile** — a shared bundle from another user, validated before activation.

Because profiles are stored locally, you remain in full control of your data at all times.

## ❓ Frequently Asked Questions

**Is this companion officially affiliated with the game publisher?**
No. It is an independent, fan-made utility and is not endorsed by or connected to the publisher.

**Will it affect my save files?**
The companion is designed to operate alongside your game without modifying save data. Always keep backups as a good habit.

**Does it require an internet connection?**
Core features work offline. Network access is only used for optional updates and community-shared profile bundles.

**Can I use it on multiple machines?**
Yes. Profiles can be exported and imported manually.

**Which languages are supported?**
See the Multilingual Support section above. New languages are added as translators volunteer.
